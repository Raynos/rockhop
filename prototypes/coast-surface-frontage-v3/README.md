# Coast surface + frontage V3: isolated art review

**Status:** source-only integration candidate. No Vite build, actual-game moving
comparison, performance measurement, or course acceptance has been made from
this patch. This does not move C1 beyond its bounded accepted harbor assets.

`runtime.patch` is generated by `make-patch.py` against the accepted current
Coast hook, not the older `bdf002fa` prototype. It changes four private
runtime modules only. The committed Blender deliveries are input assets;
production `src/`, `public/`, generated catalogs, and build caps stay intact.

## Intended A/B

`prepare-pair.mts` freezes all 352 current `src` files, public assets, the
external world-map sky, root build files and the small harness type imports
once. It adds the same unpublished Coast frontage bank and nine ground maps
to that frozen public bank **before** cloning it into `before` and `after`.
Only `after` receives `runtime.patch`; both phases use the same app, rider,
camera, physics, existing model bytes, and complete 68-file model bank. Each
private phase has a Vite config with an explicit `load` override for the four
patched modules. This prevents a concurrent production edit from leaking into
one side of a timed comparison. The private build uses an unmodified copy of
`vite.config.ts`, including the 700 KiB gzipped player JS limit. An over-budget
private build is a failed gate, not an allowable prototype exemption.

The `before` source still requests the accepted Coast harbor bank and uses its
current ground. Unused frontage/ground files appear in both catalogs solely
to keep the asset inventory matched. The `after` source requests the new
frontage GLB pair, retains all seven earlier Coast prototypes, and places
brick sheds at x32/370, sawtooth halls at x109/450, and the original shed at
x282. All five reuse the accepted footprint, y and z anchors. The renderer
passes `ribbons.group` into the biome hook; after the owned nine-map ground
transaction and harbor owner both mount, only named Coast deck tops, quay
faces, and terrain receive the new material. The edge stripe, obstacles,
supports, site props, and sea are untouched. Failed or canceled delivery
keeps or restores borrowed materials; a late delivery cannot swap after
course retirement.

## Reproduce and review

From the repository root, create a **new** temporary output directory:

```sh
pnpm exec tsx prototypes/coast-surface-frontage-v3/prepare-pair.mts /tmp/rockhop-coast-v3-pair-new
```

The script refuses to run if pinned live integration files drift, if the
output exists, or if any source changes during the freeze. It writes
`pair-inputs.json` and the two private roots. No build is performed. To build
after the parent reserves the build/browser lane:

```sh
cd /tmp/rockhop-coast-v3-pair-new/before
VERCEL_GIT_COMMIT_SHA=<head-from-pair-inputs.json> node_modules/.bin/vite build --config pair.config.ts
cd /tmp/rockhop-coast-v3-pair-new/after
VERCEL_GIT_COMMIT_SHA=<head-from-pair-inputs.json> node_modules/.bin/vite build --config pair.config.ts
```

Retain the **actual build log** for both phases, including player bundle
bytes. If either build exceeds the mandatory cap, stop. Do not compare
stale/partial dist. With passing builds, play the same C1 Rookie full clear
and held-GO fault/retry at 852×393 landscape, identical tier, camera,
recording and timestamps. Check landing/brake visibility, warehouse
silhouette/material read through the whole ride, coast top/wall/terrain
continuity, normal Menu not decoding course meshes, missing map fallback,
late course switch, texture and draw/triangle deltas, p95 synchronized frame
and submit times. A source-only candidate cannot prove any of these.

## Prepared snapshot validation

The local prepared snapshot `/private/tmp/rockhop-coast-v3-pair-20260930-5` is
untracked and can be discarded. Its exact SHA and staged asset provenance
are in `prepared-inputs.json`. It froze at HEAD
`7b3c46819d5ee922a0d103c5cfe11eda1058491a`; both phase banks hash to
`43579456a080871413ba46579e5e00e9914a82d5b102e7f8e023a7500685b15a`.
`git apply --check --unidiff-zero runtime.patch` passed. The zero-context
patch avoids trailing whitespace inherited from unchanged source lines; its
four after-source files were checked byte-for-byte against the frozen pair.
`prepared-inputs.json` records both the patch used to construct the frozen
pair and the equivalent current patch SHA. TypeScript `tsc --noEmit` passed
for both private roots; `oxlint` passed for the four after override modules
and `pair.config.ts`. The recipe resolves `/tmp` to its canonical
`/private/tmp` source root before writing its Vite override paths. No browser,
GPU, Vite build, or production edit was run.

**Acceptance limits:** each material is only qualified after moving evidence
and lifecycle/performance gates. Both frontend banks are currently candidates,
not accepted C1 artwork. A pass here still does not sign off the whole course
or the remaining 11 courses.
