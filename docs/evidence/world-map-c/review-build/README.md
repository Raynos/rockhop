# C-island production-style review build

The selected C-island scene now has an explicit **review-build-only** switch: `VITE_MAP_3D_REVIEW=1 pnpm build`, then open `/?map3d=1` and choose Play. Without the query, the same build uses the painted selector. Normal web and store builds compile the 3D scene out; the prototype sky is emitted as `/map-review/sky-alpine-a.png` only for the review build. This makes the 3D map testable in a phone browser without replacing the live selector before its art and device gates pass.

The clean committed `f8f0095e7529f8f23a5af34ccf43ec71bfc6d8db` review build is [deployed on Vercel](https://playrockhop-2jwvxrsnf-raynos-projects.vercel.app/?map3d=1), deployment `dpl_C21C9gskm994eNGdwV6dS9vg2PHF` (`READY`). Vercel Authentication protects this preview; the account owner signs in, then taps Play. Authenticated CLI probes returned the exact `/version.json` SHA and HTTP 200 for both `/assets/worldMap3dScene-bu6fCMyu.js` (84,822 bytes) and `/map-review/sky-alpine-a.png` (1,850,562 bytes). A plain unauthenticated request returned HTTP 302. This preview did not change `main` or the public `playrockhop.vercel.app` deployment.

A silent 852×393 headless Chromium preview run produced the [phone-size map frame](phone.png) and [machine report](report.json). The production-style smoke establishes packaging and entry, not physical touch accuracy or frame pacing.

`src/store-build.test.ts` now builds normal web, store and explicit map-review variants: all 16 tests pass, including presence of the C-island scene and sky only in the review variant. The 1.85 MB sky file is likewise absent from normal and store bundles. `pnpm typecheck` and `pnpm lint` passed.
