# Snowline S1 and S3 optional Diamond routes

Both registered courses now have a one-way `open-platform` route with a grounded rear-wheel `diamondGoal`. The normal course remains open. No bike ID is used in the medal gate: either bike can earn Diamond by crossing its deck cleanly and beating the clock.

Each row in [S1 verification](s1-lift-line-verify.json) and [S3 verification](s3-whiteout-verify.json) has the same physics finish value, run hash, route proof, and fault count in Node and two fresh headless browser loads. All four runs finish cleanly. The Pro's top medal is represented as `platinum` internally. A Rookie can earn it with a qualifying upper line; the sampled counts show an advantage, not exclusivity. The [S1 input sweep](s1-lift-line-input-sweep.json) and [S3 input sweep](s3-whiteout-input-sweep.json) vary throttle and lean in two jump windows from each bike's measured clean approach. They count survival only through the feature; the linked full recordings prove the later clear. The [S1 candidate sweep](s1-candidate-sweep.json) and [84 S3 deck candidates](s3-candidate-sweep.json) record placement screening. The first S1 placement at x=285–295 m let Rookie held GO finish after an early fault; moving the shelf to x=288–298 m restored the challenge gate. The first S3 shelf favored Rookie crossings and was rejected. Six 600-second held-GO runs per course—both bikes on the default seed and seeds 1 and 2—had no clears: [S1](s1-lift-line-passive.json), [S3](s3-whiteout-passive.json).

The first S3 Rookie continuation caused three R8 recovered-pose violations near x=151.8 m (maximum angular residual 0.432 rad against 0.35 rad). The replacement lets the bot take control at x=150 m and has [zero violating ticks](s3-r8-probe.json). A shadow copy of the full, unchanged [R8 test](s3-r8-shadow-test.log)—73 input goldens with only S3 Rookie substituted—passed all five tests and printed `R8 residuals: none`. The shared golden now uses this replacement; the original R8 test and the serial 97-file suite pass.
