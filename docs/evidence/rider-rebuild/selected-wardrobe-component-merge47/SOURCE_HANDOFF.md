Source adapter only. Parent serial CPU2/global-memory guard owns every native
execution and judgment. No Blender, merge, witness, merged replay, export,
played review or promotion was executed by this builder.

complete native-open/transplant/material-reuse/ID-cleanup/pointer/rest/action/
scratch-release block unchanged. Only input intake, actual recipe identity,
output directory and native filename change. Frozen lineage38 stays unchanged;
its actual `target_gate` validates the independently qualified target receipt.

`35815e62180aabc37588668f426d3709bad139b5f50d6b1f82ccfa60af848ce8`.

## Parent execution

Each Blender invocation below needs a separate unchanged parent guard. The
ordinary Python freeze/compare commands do no native operation. These are
concrete commands, not evidence that they have run:

```sh
recipe=assets/blender/rider-rebuild/selected-sleeve-component47
component=harness/out/rider-rebuild/selected-sleeve-component47/component01
merged=harness/out/rider-rebuild/selected-wardrobe-component-merge47/merge01

python3 "$recipe/merge47.py" freeze "$component/construction.json" "$component/dense-summary.json" "$recipe/merge-input01.json"
"$BLENDER" -b -t 2 --python-exit-code 1 --python "$recipe/merge47.py" -- merge "$recipe/merge-input01.json" "$merged"
"$BLENDER" -b -t 2 --python-exit-code 1 --python "$recipe/merge47.py" -- target "$merged/pending.json"
"$BLENDER" -b -t 2 --python-exit-code 1 --python "$recipe/merge47.py" -- source "$merged/pending.json"
"$BLENDER" -b -t 2 --python-exit-code 1 --python "$recipe/merge47.py" -- merged "$merged/pending.json"
python3 "$recipe/merge47.py" compare "$merged/pending.json"
"$BLENDER" -b -t 2 --python-exit-code 1 --python "$recipe/merge47.py" -- replay "$merged/receipt.json" "harness/out/rider-rebuild/selected-wardrobe-component-merge47/replay01"
```

The one merge changes only the three mesh datablocks: `RiderHoodie` and
`ActualSelectedGlove.L/.R`. It retains destination objects and selected materials;
all unrelated native10 geometry, shape keys, masks, original75 rest, actions,
pose state, frame and timing remain subject to independent comparison.

The raw uncompressed output is
`UNACCEPTED-selected-dressed-component47.blend`. Saving does not qualify it.
Each `target/source/merged` witness opens only its own saved native in a new
process. The donor scene is required to contain exactly component47's five
objects and three visible meshes. The target and merged scenes retain the
complete seven-mesh wardrobe and body mask. No complete source master95 is
opened or preflighted.

The native10 inspection helper supplies its unchanged full geometry/PBR/bind
fingerprint, original08 supplies its unchanged complete named-weight digest,
and the helper supplies original key/action state. The fingerprint retains
positions, topology, every supported attribute, exact UV flags/values, normals,
material scalar RNA, material/node/socket/image names and bytes, links,
transforms, modifiers, visibility and scalar object properties. Selected material
identity is never waived. Source vs merged wardrobe and source vs target complete
reference must match; target vs merged unrelated parts, keys, actions and rig
must match. Source witnesses never claim an absent body mask or gameplay action.

The constructor's `Surgery.finish` changes mesh and group data; inspection found
no object custom-property mutation there. This merger therefore keeps the full
fingerprint intact rather than dropping bookkeeping or weakening PBR comparisons.
A material-name or image-name mismatch is a rejection requiring an intake fix.

Only the three separate native witnesses and comparison issue `receipt.json`.
It records the target's actual replay pass and keeps `mergedReplayPassed=false`,
`poseEnclosurePassed=false`, and `movingReviewPassed=false`. The final separate
replay uses exact original08 captured matrices, original action records, shape-zero
checks and unchanged 0.1 mm affine bound over both 241-frame actions. It releases
Python pose/package allocations before opening the merged native and emits a
new source-only replay receipt without resaving the candidate.

The resulting real full-outfit native can enter the existing full-outfit export
pipeline. Actual game forward/back lean footage, clothing enclosure/contact,
wrist/ankle review, mobile/device review and parent art judgment remain required.
Nothing here authorizes a generic surrogate, component-only player asset, or
normal-player promotion.
