# Pinned-native read-only review renderer

`render.py` opens an explicit hashed native and renders the named actual meshes with the full body visible. Fixed640px studio lighting, Cycles CPU2 and optional saved-action film keep comparisons consistent. Explicit focus/orthographic scale/view positions permit glove and foot detail diagnosis without changing models. Stills can reject gross defects, never accept moving art. No native file saves, material substitution or model exports.
