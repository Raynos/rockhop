# Corrected sleeve delivery compiler

This compiler writes a fresh private staging packet. It never changes
`public/` or the production `selectedAsset.ts`.

The constructor provides `selected-cuff-source-parity-v1`, an exact candidate
GLB and its pinned fit report/patch. The parent supplies a verified immutable
upload receipt. Run the compiler only after candidate/job admission, using
the existing original bounded shared guard:

```sh
python3 assets/blender/rider-rebuild/focused-delivery07/compile.py \
  --candidate harness/out/rider-rebuild/selected-cuff-finish06/candidate01/rider.glb \
  --parity harness/out/rider-rebuild/selected-cuff-finish06/candidate01/parity.json \
  --source-receipt PARENT_UPLOAD_RECEIPT \
  --out harness/out/rider-rebuild/focused-delivery07/stage01
```

The output includes raw and normalized contracts, immutable manifest,
`selectedAsset.ts`, source parity, profile transfer and a pinned stage report.
The normalized `nativeRest`, all75 roles/specification, every actual driver
control and selected maps remain exact. Profile authoring f814/030108 stays
distinct from measured baseline585a and the new application source.

The independent verifier checks every decoded accessor hash, native/material
JSON records, image payload hashes and the actual original BIN prefix.
Only enumerated hoodie POSITION/NORMAL/TANGENT/JOINTS_0/WEIGHTS_0 may differ;
all remaining accessor certificates must cover the complete accessor domain.
Every glove attribute and index stream needs its own exact certificate.

The moving harness accepts the distinct `selected-cuff-profile-transfer-v1`
packet and rechecks the source prefix, all metadata/payload coverage and
normalized rest/pose driver. Its original generic decoded-graft branch retains
its existing assertions. Source correction never claims changed hoodie fields
remain protected-exact. Exact gloves/native rig/driver support inherited bar
measurements; the parent still judges new-source movies and owns replay,
ship gate, promotion, checked deploy and physical iPhone performance.

Parser/serializer checks require no browser or derivative decode job:

```sh
node --test assets/blender/rider-rebuild/focused-delivery07/transfer.test.mjs
python3 assets/blender/rider-rebuild/focused-delivery07/test_compile.py
```

Test fixtures certify parser behavior only. They are not source parity,
upload, staging, moving-art or device acceptance evidence.

Once the parent supplies the fresh compiled packet/build and admits the run,
the capture launcher verifies their exact identities before starting:

```sh
python3 assets/blender/rider-rebuild/focused-delivery07/capture.py \
  --packet harness/out/rider-rebuild/focused-delivery07/stage01 \
  --source harness/out/rider-rebuild/selected-cuff-finish06/candidate01/rider.glb \
  --build PARENT_SUPPLIED_PRIVATE_BUILD \
  --out harness/out/rider-rebuild/focused-delivery07/played01 \
  --evidence docs/evidence/rider-rebuild/focused-delivery07/played01
```

The launcher uses the original shared admission helper and bounded guard for
serial Rookie and Pro forward/back leans followed by one full18second Garage
orbit. Each job has its original420second bound. Diagnostic lean framing
retains the original3m/review zoom2.2 and Rookie.8/Pro2.35 yaw for comparable
cuff/hand pixels. Garage uses two trusted outward120 wheel gestures within the
normal player limits. The parent verifies full head/boots in the played movie.
`--garage-bike=pro` selects Pro for the single Garage orbit; Rookie is default.

Compiled JS/WASM/HTML and packet/catalog/version bytes are pinned before and
after every capture. Version metadata alone does not prove the compiled source
revision; the parent owns build freeze/provenance. Fresh output directories
are required. Failed jobs retain guard/report/movie evidence and stop without
automatic retries. No exhaustive contact job is repeated: exact glove/native/
driver proof supports inherited finite-bar measurements only. All captures
remain unaccepted until parent judgment. Mac CPU render-submission FPS and
encoded movie cadence do not establish GPU completion or physical iPhone FPS.
