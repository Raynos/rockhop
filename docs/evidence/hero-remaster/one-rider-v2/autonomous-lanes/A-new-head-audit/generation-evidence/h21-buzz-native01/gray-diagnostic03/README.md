The CPU-two-thread audit completed 52 actual renders: four variants, each four face views plus a nine-angle board. Painted PBR and gray use the parent-reviewed X180 display, raw and reduced use their native imported frame; shared camera, lights and normalization are recorded. There is a small export translation difference, and exact per-vertex correspondence is not claimed. Source bytes are unchanged.

Both black cheek defects persist in gray and in the native shape retained before cleanup and FaceReducer. A read-only positional coincidence diagnostic reports 111 boundary edges, all near the two cheeks, in raw, reduced and painted meshes. At both visible black centers, rays pass through the absent front surface to the back head; neighboring rays hit the cheek. This supports actual open cheek holes already in the native source, rather than a paint-only or reducer-only defect. Coincidence tolerance is 0.1 micrometre and is not a topology acceptance or repair. Painted UV splits produce 21,359 index boundary edges; those are not 21,359 physical holes.

Raw source retains all 985,183 triangles. Blender imports/renders 985,175, omitting eight repeated-index zero-area triangles, exactly accounted for in the existing raw-index forensic. No valid source triangle was silently removed for rendering. Raw floating islands are visible and preserved.
