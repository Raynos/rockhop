# Native articulation around a literal 18 mm handle

Unaccepted one-hand deformation experiment. No complete-body source, runtime
rig, normal player asset or physics setting changed. Native anatomical L is
runtime semantic R after the parent's proper rotation and explicit side remap.

The first build stopped at a legitimate cylinder-placement guard: a fixed MCP
plane and one-dimensional normal-offset search did not provide 18.5 mm open
skin clearance. That failed recipe, log and receipt are preserved. The geometric
correction searched both longitudinal and palm-normal placement using actual
native skin clearance and MCP pivots. It produced the actual 33-frame buffer and
passed rest-position and wrist assertions, then failed while serializing its
report because an optimizer float reused the placement-result variable name.
The metadata error is preserved; it does not count as successful build exit.

The exported buffer was rendered without rerunning or correcting that failed
recipe. Three actual silent clips show open → wrap → open at 16 fps from front,
palm and profile views. Each clip contains 33 frames, generated by the measured
native bone pivots and original skin weights. The exact 18 mm cylinder is green.
The gray surfaces use recomputed deformed geometry normals; no PBR claim is made.

## Measured results

- All 33 native skin buffers are finite; wrist-rim displacement is exactly zero.
- The first and last open poses preserve the original rest positions.
- Worst continuous triangle/cylinder penetration is 0.1564 mm; no tested
  triangle penetrates more than 1 mm. Every hand triangle falls within the
  finite handle's ±80 mm axial range, so the radial test covers this cylinder.
- All five fingers have actual skin vertices within 1 mm of the handle.
- Maximum wrap adds 21 nonadjacent triangle BVH overlaps; the rest hand has zero.
  This diagnostic excludes triangle pairs sharing a vertex. It is not an
  accepted self-intersection result and requires the parent's inspection.
- Minimum triangle-area ratio across motion is 0.105. Against-rest normal
  opposition is reported separately and cannot classify a fold by itself,
  because finger rotation legitimately changes normals.

The played result is a distal-finger hold, not a convincing full palm wrap.
Contact distances alone must not accept it. The thumb barely articulates and
the coordinate search mainly bends PIP/DIP joints. No appearance score or
contact gate is assigned by this builder.

## Reproducible output and alternative

The private runtime native-hand-animation.npz contains complete vertex IDs,
untouched source positions, maximum-wrap positions, morph deltas and all 33
played buffers. Its hash is in buffer-audit.json. Original native source hashes
remain unchanged. These deltas are an unaccepted candidate for a later 19-bone
hand rest/morph adapter, not an applied rig.

The next specific alternative is to constrain the handle against an actual
distal-palm surface witness rather than minimizing open-hand clearance, solve
thumb abduction/opposition first to clear the handle, and use native MCP/PIP/DIP
inverse kinematics with continuous surface collision constraints. Compare
volume-preserving dual-quaternion deformation with the current linear blend
before baking the chosen hand geometry. Those changes are untested and should
not be conflated with the retired canned fixed-curl method.

All runs used two CPU threads in the isolated owned environment and remained
inside the shared 30-minute batch ceiling. No GPU/model/package job was run.
