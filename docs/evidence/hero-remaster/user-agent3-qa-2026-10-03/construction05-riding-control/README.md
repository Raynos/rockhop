# Rejected wardrobe control: actual riding and proposed contacts

The human rejected the current hoodie, jeans and footwear as finished
clothing: glued/plastic deformation, tearing, poor enclosure and exposed
toes. The simple Garage mannequin's proportions and movement remain a
useful baseline. These eight films preserve the rejected wardrobe as an
engine/contact control; numerical findings do not qualify wearable fit.
No further cosmetic capture of this top is proposed.

The exact zero-default 05 full candidate uses the normal game pose on the
live Rookie/Pro bike. Each film replays recorded inputs from tick 1 to its
chosen forward lean, backward lean, front landing or rear landing window.
The private controller changes only morph weights, reading verified local
rest-relative bone angles. It drives both separate hoodie primitives and
jeans. Bones and physics receive no authored pose injection.

`engine-receipt.json` pins candidate/master/controller, input recordings,
normal loader/materials, every captured camera and bike/rider transform.
All 152 captured frames retain the whole deformed rider in frame. The eight
films play silently and completely. Every input tick is rendered and traced
in its `.ndjson` file. `every-tick-physics.json` independently replays the
production Game and matches all 15,988 browser hashes, ticks, phases, run
clocks and finish fields exactly. These windows end while riding; they are
not a new clear/restart or attempts-to-clear result.

Clearance is sampled at every selected triangle centroid and unique vertex.
Nearest shell distance and local face-sided distance are recorded separately.
Closure/orientation is unproved, so local sided distance is **not** a volume
penetration claim. Peg/saddle support considers only rest faces with positive
bike-frame Y normal. Each rider sample must project at the same bike-frame
X/Z into an upward triangle; the highest projected face supplies the signed
bike-up gap. Undersides, side faces and a merely nearby saddle nose cannot
become support through a nearest-distance shortcut. No acceptance threshold
or pass flag is invented. Degenerate projected faces are explicitly skipped.
The live target/rest-frame matrix residual stays below `1.137e-13`.

lean, the nearest jeans/saddle shell gap is about 0.1 mm, while some projected

is 111.9 mm. Those are sampled patch facts, not proof of correct seated support
or volume penetration. Boot projection gaps are about 8.6 mm at the selected
centers; this says nothing about enclosing toes, heel or ankle.
