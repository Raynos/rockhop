# Optional Diamond route engine — 2026-09-28

An authored `open-platform` is a one-way upper deck with a clear lower passage. An opt-in `diamondGoal` records whether the grounded rear wheel crossed a named plane while contacting that deck. A clean fast clear without the crossing is capped at Gold; ordinary tracks keep their previous medals and hashes. The crossing enters the deterministic run hash, result and replay header. Existing top-medal saves remain grandfathered, and a slower proved Diamond keeps a separate recording without replacing the fastest PB ghost.

[Exact verification](proof.json) ran a synthetic upper and lower route through Node, replay and a silent headless browser. The upper route finished on tick 645 with zero faults, route proof true and top stored medal `platinum` (shown as Diamond); all three hashes were `c794f2dea6deb896`. The lower route finished on tick 803 with zero faults, route proof false and Gold; all three hashes were `4be35aa24474171d`. Malformed deck goals and solid overlaps are rejected by track compilation. No D3/S1/S2/S3 course geometry uses this engine yet, and the proof does not establish a Pro-only physical line.

Qualification on the combined branch: 97 test files, 1,405 passed and two skipped; typecheck, lint, web build (639.9/640 KB gzip) and store build (632.2/640 KB gzip) passed. The [four-section ship gate](ship-gate.partial.json) passed recorded clear/hash, crash-to-control and one-tick restart. SwiftShader missed ready-to-first-frame (5,857 ms vs 4,000) and restart synced-frame p95 (345 ms vs 150), so this is **NO-SHIP** and stays off production `main` pending device performance and the full gate.
