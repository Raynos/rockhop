**Status:** active; approved by the user on 2026-09-28. This is the release path above the [current session rounds](REMASTER_CURRENT_ROUND.md). The [ranked top 20](GAME_REMASTER_TOP20.md) explains the quality findings; the [12-course brief](COURSE_AND_PROGRESSION_REDESIGN.md) carries the course design. A milestone closes only with played evidence on its candidate source. No estimate or passing bot result by itself declares the game finished. Archive this plan under `project/archive/` only after all six gates pass and the public release is verified.

## Release we are building

One complete, landscape-only game on **iOS and Android together**: the 12 main courses across coast, alpine, quarry and snow; the rotatable 3D C island with 12 rally-flag towers; two bikes with an earned 800-Scrap Pro unlock; Bronze, Silver, Gold and Diamond; saved progress, personal bests, retry and replay. The first public release is **free, with no ads or in-app purchases**. The accepted finish layout and selected C island reference remain the visual directions. These choices came from the user; changing them requires a new decision.

“Finished” means a new player can learn why a crash happened, immediately retry, earn the second bike through play, finish the campaign, and want a better medal. The whole game must hold up in motion on a supported phone, not only in a screenshot or deterministic bot replay. The [mission bars](../mission.md) remain the long-term art, sound, performance and fun direction; this plan sets measurable release proxies.
