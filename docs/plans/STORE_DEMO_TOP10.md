# ROCKHOP playable store demo — ranked finish list

**Status:** active · 2026-09-27 audit, updated 2026-09-28. This is the short release order for both iOS and Google Play. The detailed iPhone gates are in [IOS_APP_STORE_FINISH.md](IOS_APP_STORE_FINISH.md), and store build/account steps are in [STORE_RELEASE.md](STORE_RELEASE.md). A live website or a green unit suite alone is not a store-ready game.

| Rank | Outcome and pass condition | Current state |
|---|---|---|
| 1 | **Choose and ship the 3D world map.** Compare moving B/C standalone prototypes against their mockups; select one, then replace the painted map with a genuine rotatable four-biome scene, road and exactly 12 clickable rally flag towers. Keep unlock/progress state and 44-point touch targets. | B/C prototypes in progress; old painted map still ships. |
| 2 | **Prove the release loop on actual courses.** Cold boot → C1 select/clear → crash → one-tick restart, then a later biome and both bikes. Node, web and native finish bytes/hashes must agree on the exact release source. CI, full ship gate and `/version.json` must name the same committed SHA. | Partial C1 gate 10/11; software first-frame red. New web host live, CI deploy token red. |
| 3 | **Make startup feel finished.** Verify the fixed menu art/buttons, portrait rotate instruction, stable loader and seamless iOS splash on an installed phone. Reduce the measured 12.38-second matched cached boot toward ≤5 seconds on iPhone without a garage-swap hitch or sacrificing the full offline pack. | Code fixes and headless layout proof; phone timing and installed-PWA proof open. |
| 4 | **Qualify all 12 main levels.** Fresh bot sweeps and independent strangers must expose attempts-to-clear, restart latency, camera/visibility and difficulty outliers. Check both bike classes, unlocks and persisted saves after the map replacement. | Four Free Rides removed; older recordings are historical. |
| 5 | **Pass real-device play.** On iPhone and Android, check landscape orientation, safe areas, touch comfort, 20-minute frame/thermal behavior, offline boot, interruption/resume and progress retention. The user judges moving clips and actual device play. | Simulator/headless evidence only; physical-device gate open. |
| 6 | **Make the rights and content answers true.** Resolve the beard licence and other external asset provenance; align `store/COMPLIANCE.md`, credits and both store forms with the actual signed payload. Strict IP audit must stay at zero. | Build scan green; rights declaration still conflicts with provenance. |
| 7 | **Publish real privacy and support pages.** Provide the public support address, place the pages at the verified ROCKHOP host, and verify their HTTPS responses and links from a fresh client. | `playrockhop.vercel.app` serves the game; `/legal/*` is 404; support address HR-19 open. |
| 8 | **Replace store media.** Capture landscape screenshots from the final player UI with touch controls where visible; review every caption against the release build. Discard the old Trials Gauntlet trailers; if using an app preview, record ROCKHOP gameplay from that build. | Current screenshots omit normal controls in many ride frames; trailers are old-brand. |
| 9 | **Sign and distribute release candidates.** Build one traceable iOS archive and Android App Bundle from the gated source, then test through TestFlight and Play Console. For a new personal Google Play account, a closed test needs at least 12 opted-in testers for 14 continuous days before applying for production access ([Google policy](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en-GB)). | Native shells compile; store accounts HR-16, Google testers HR-20, and signed phone builds open. |
| 10 | **Submit matching listings.** Confirm version, screenshots, privacy labels, rating, rights, support URL and reviewer notes against the exact signed binaries; send to Apple/Google after the human gameplay review and required account/test steps. | Hold until ranks 1–9 pass. |

**Immediate dependency chain:** judge B/C moving prototypes → build the selected map → run the exact-source gate and device tests → recapture media → sign/test → submit. Token replacement for GitHub Actions and the support address can proceed in parallel. The old Trials Gauntlet production project remains available until the new project's CI deployment and SHA check pass.
