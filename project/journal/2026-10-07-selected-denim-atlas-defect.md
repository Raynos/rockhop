# Compact denim interpolation crosses the original atlas

Finding: 8,830/16,000 executed selected jeans triangles mix distinct original
UV charts. Independently projecting each compact corner onto a valid source
triangle does not preserve the texture atlas inside the compact triangle.
The original dense source has 43,284 charts; geometry-fit repair alone cannot
remove this measured appearance defect. Parent selected a coherent compact
unwrap with dense original appearance/detail bake and intact source masters.

Validation: all 48,000 recorded jeans corners match actual exported GLB UVs
exactly as float32 after the V flip. Independent exact-bit seam-duplicated
corner graph confirms every mixed-face classification and chart count. Both
array-only scripts pass with warnings promoted to errors. Centre samples
show median 483-pixel original-versus-interpolated UV error at 4K. No source,
native, normal player asset, browser or build was changed or executed.

Limits: centre nearest searches are bounded candidate diagnostics, not global
BVH proof. Boot prototype ancestry has 67.94% mixed charts, but its executed
corner transfer was not persisted and remains unmeasured. Original artwork
also contains genuine fabric wrinkles; this finding does not judge every
visible patch or accept any final moving appearance.
