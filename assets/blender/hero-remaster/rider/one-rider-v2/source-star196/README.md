# Source-star196 scalar trial

One registered construction from the frozen195 parent contract. The build
appends one clone per released source accessor row, remaps only interior
corners in the original168 faces, and preserves original XZ and all original
array rows. Its Float64 stations use the cumulative final path entry. New
normals use physical ID plus exact original NORMAL bits, independent of UV.

The actual Float32 dump rejects before export:44 strict crossings and9 source
normal-group reversals. No GLB, render, rig adapter or motion trial exists.
Parent owns judgment and integration. See the corresponding evidence report.

`run.py` is the single-attempt CPU runner. It refuses existing attempts and
must not be rerun to construct another candidate. `verify.py` reads the frozen
dump for auditing; it does not tune or rebuild geometry. Predicate AST imports
select named readers/functions only and never run earlier recipes. Full dump,
provenance, topology, strain, crossing pairs, rooted labels and exact replay
input snapshots are retained in the private source-star196 runtime directory.
