# A192 one local surgery and dump verification

`build.py` generates one registered mesh and refuses an existing dump.
`verify_dump.py` loads that same retained geometry and verifies it without
regenerating it. Both use installed UniMate Python, CPU2 environment limits,
no renderer/GPU/model,890s deadline and anonymous70GB ceiling. The exact69-face
excision produced a malformed physical boundary and is rejected before export.
Evidence/private dump lists retain the actual generated mesh and all witnesses.
