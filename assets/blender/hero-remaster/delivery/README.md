# Private whole-hero candidate

This directory is preserved on the private `codex/hero-remaster-review` branch.
It is not a production model promotion. `mapping.json` resolves six frozen
Street rider and Rookie/Pro full+LOD exports for the private real-game builder.
All five outfit and both bike choices remain; the other four riders use their
existing files. Read the [moving judgment and limits](../../../../docs/evidence/hero-remaster/delivery/README.md)
before treating these first candidates as accepted art.

Rebuild with the pinned recipes under the adjacent `bike/` and `rider/`
directories and the localai UniMate merge wrapper. The runtime ships only baked
GLBs: no Python, neural inference, checkpoint, cache or venv is delivered.
